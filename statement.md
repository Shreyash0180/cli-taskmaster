# Problem Statement
Many individuals struggle with managing their daily tasks efficiently, leading to missed deadlines and decreased productivity. Existing graphical task management tools can be overly complex and distracting.

# Scope of the project
This project is a Command-Line Interface (CLI) based Task Management System designed to provide a fast, distraction-free environment for users to track, organize, and analyze their tasks.

# Target users
- Software Developers
- Students
- Terminal-enthusiasts and power users who prefer keyboard-centric workflows

# High-level features
- User authentication and personalized task lists.
- CRUD operations for tasks (Create, Read, Update, Delete) with priority and status tracking.
- Analytics module to summarize task completion rates and pending workloads.
